\doxysubsection{Detailed Description}
mapelli20 option

Fit (based on the pre\+SN \mbox{\hyperlink{class_m_h_e}{MHE}} core mass) to the Woosley17 tables as reported in the Appendix of Mapelli+20 (see also Spera+17) see\+:
\begin{DoxyItemize}
\item Mapelli+20\+: \href{https://ui.adsabs.harvard.edu/abs/2020ApJ...888...76M/abstract}{\texttt{ https\+://ui.\+adsabs.\+harvard.\+edu/abs/2020\+Ap\+J...\+888...\+76\+M/abstract}}
\item Spera+17\+: \href{https://ui.adsabs.harvard.edu/abs/2017MNRAS.470.4739S/abstract}{\texttt{ https\+://ui.\+adsabs.\+harvard.\+edu/abs/2017\+MNRAS.\+470.\+4739\+S/abstract}}
\item Woosley+17\+: \href{https://ui.adsabs.harvard.edu/abs/2017ApJ...836..244W/abstract}{\texttt{ https\+://ui.\+adsabs.\+harvard.\+edu/abs/2017\+Ap\+J...\+836..\+244\+W/abstract}}
\end{DoxyItemize}

Modification with respect to the standard
\begin{DoxyItemize}
\item apply\+\_\+before\+SN\+: no modifications
\item apply\+\_\+after\+SN\+: apply corrections based on finale core He mass, correct Mremnant and set sn\+\_\+type Approximately\+: 32\texorpdfstring{$<$}{<}\mbox{\hyperlink{class_m_h_e}{MHE}}\texorpdfstring{$<$}{<}64 PPISN SN, 64\texorpdfstring{$<$}{<}\mbox{\hyperlink{class_m_h_e}{MHE}}\texorpdfstring{$<$}{<}135 PISN (no remnant) (the fit depends also on MHE/\+MTOT) 
\end{DoxyItemize}
