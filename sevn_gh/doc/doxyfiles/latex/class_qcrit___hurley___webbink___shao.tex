Same qcrit from Hurley+02 with Webbink 1988 for giants, but with a special treatment accretion on a BH following the Shao+21 paper. In the Shao+21 paper (\href{https://arxiv.org/pdf/2107.03565.pdf}{\texttt{ https\+://arxiv.\+org/pdf/2107.\+03565.\+pdf}}) there is a special treatment for the accretion on a BH. Therefore if the accretor is not a BH we use the classical qc from Hurley. In Shao+21 there is not really a constant value for qc, but there are a number of criteria that we have to take into account to estimate the stability of the mass transfer, then if the mass trasnfer is stable we use a very large value for qcrit otherwise a very small one.
