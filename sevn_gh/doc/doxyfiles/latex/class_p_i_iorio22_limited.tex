\doxysubsection{Detailed Description}
iorio22\+\_\+limited option

Same as iorio22 but with an upper limit on the PPISN BH mass following Eq. 2 in Farmer+19 see\+:
\begin{DoxyItemize}
\item Farmer+19\+: \href{https://ui.adsabs.harvard.edu/abs/2019ApJ...887...53F/abstract}{\texttt{ https\+://ui.\+adsabs.\+harvard.\+edu/abs/2019\+Ap\+J...\+887...\+53\+F/abstract}}
\end{DoxyItemize}

Modification with respect to the standard
\begin{DoxyItemize}
\item apply\+\_\+before\+SN\+: modify the pre\+SN mass
\begin{DoxyItemize}
\item MCO$<$38 Msun or MHE$>$135 Msun -\/\texorpdfstring{$>$}{>} not modifications
\item \mbox{\hyperlink{class_m_c_o}{MCO}}\texorpdfstring{$>$}{>}=38 Msun and (\mbox{\hyperlink{class_m_h_e}{MHE}}\texorpdfstring{$<$}{<}=135 Msun)-\/\texorpdfstring{$>$}{>} \mbox{\hyperlink{class_mass}{Mass}}=\mbox{\hyperlink{class_m_h_e}{MHE}}=\mbox{\hyperlink{class_m_c_o}{MCO}}
\end{DoxyItemize}
\item apply\+\_\+after\+SN\+:
\begin{DoxyItemize}
\item MCO$<$38 Msun or MHE$>$135 Msun, no mass correction -\/\texorpdfstring{$>$}{>}Core Collapse
\item 38 Msun\texorpdfstring{$<$}{<}=\mbox{\hyperlink{class_m_c_o}{MCO}}\texorpdfstring{$<$}{<}=60 Msun, limit BH mass using the $\ast$\+MBH\+\_\+max from Equation 2 in Farmer+19 -\/\texorpdfstring{$>$}{>} PPISN $\ast$\+MBH\+\_\+max=35.\+1 -\/3.\+9 log10(\+Z) -\/0.\+31 log10(\+Z)$\ast$log10(Z), where Z is the metallicity
\item \mbox{\hyperlink{class_m_c_o}{MCO}}\texorpdfstring{$>$}{>}60 Msun and (\mbox{\hyperlink{class_m_h_e}{MHE}}\texorpdfstring{$<$}{<}135 Msun), set Mremnant to 0 -\/\texorpdfstring{$>$}{>} PISN 
\end{DoxyItemize}
\end{DoxyItemize}
