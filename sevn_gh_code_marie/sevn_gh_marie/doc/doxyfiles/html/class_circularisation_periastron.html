Detailed Description

periastron option Circularisation at periastron: anew=a_old(1-e_old)

After the circularisation the binary angular momentum decreases of a factor (Jnew-Jold)/Jold = 1/sqrt(1+e) -1, it ranges from 5% for small eccentriciteis (e=0.01) to ~29% for e->1
