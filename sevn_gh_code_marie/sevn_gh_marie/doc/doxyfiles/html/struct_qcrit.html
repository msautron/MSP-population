Use the COMPAS prescriptions taken from Neijssel+2019, section 2.3 This implementation is taken directly from COSMIC (https://github.com/COSMIC-PopSynth/COSMIC/blob/develop/cosmic/src/evolv2.f). In the documentation they report: "We convert from radial response to qcrit for MS and HG, which assumes conservative mass transfer, Stable MT is always assumed for stripped stars, Assume standard qcrit from BSE for kstar>=10"
