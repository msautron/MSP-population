Estimate the fallback f\+\_\+b to correct the kick, i.\+e. Vk\+\_\+new = Vk\+\_\+old $\ast$f\+\_\+b, where f\+\_\+b = (1-\/fallback) The fallback is introduced in the rapid and delayed SN model as

fallback = (Mremnant -\/ Mproto) / (Mpre\+SN -\/ Mproto)

where Mproto depends on the SN model, in SEVN Mproto = 1.\+1 for rapid and 1.\+15 for delayed

However, the Sn model can set the fallback, therefore in this method we firstly check if the fallback in the SN model is set (i.\+e. \texorpdfstring{$>$}{>}=0), in this case we use the value set by the SN model otherwise we use the equation above assuming Mproto=1.\+1 Msun.
