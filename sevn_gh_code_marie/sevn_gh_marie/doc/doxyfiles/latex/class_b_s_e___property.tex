\doxysubsection{Detailed Description}
Basic Abstract class to initialise a BSE property and evolve it. When created a Class property gets all the needed coefficient, then the value can be called with the overloaded operator (\mbox{\hyperlink{class_mass}{Mass}}) or (\mbox{\hyperlink{class_mass}{Mass}},time).
