\doxysubsection{Detailed Description}
option lattimer89

Apply the neutrino mass loss correction from Lattimer\&Yahil89. \href{https://ui.adsabs.harvard.edu/abs/1989ApJ...340..426L/abstract}{\texttt{ https\+://ui.\+adsabs.\+harvard.\+edu/abs/1989\+Ap\+J...\+340..\+426\+L/abstract}} as reported in Eq. 4 in Giacobbo \& Mapelli 2018 (\href{https://arxiv.org/pdf/1805.11100.pdf}{\texttt{ https\+://arxiv.\+org/pdf/1805.\+11100.\+pdf}}). In addition, the neutrino mass loss is limited to 0.\+5 Msun.
