GI 19/07/2022, New idea to take into account the variation of stellar rotation in the adaptive time step. Similar to the \mbox{\hyperlink{class_eccentricity}{Eccentricity}}, we can have very small timesteps when the stellar rotation is close to 0, this a problem especially when we initialise the star with 0 initial spin. In this case, if we do not perform any check a too large timestep in the Main Sequence can bias the binary evolution. Since the angular momentum has a large dynamic range, I chose to use the derived property \mbox{\hyperlink{class_spin}{Spin}} to check the low velocity regime. \mbox{\hyperlink{class_spin}{Spin}} is defined as the ratio between the angular velocity and the critical angular velocity, therefore its values are always within 0 and 1. If \mbox{\hyperlink{class_spin}{Spin}} is less than 0.\+1, we adapt the timestep to guarantee that the spin is increased at most of 0.\+01. If \mbox{\hyperlink{class_spin}{Spin}}\texorpdfstring{$>$}{>}0.\+1, we use the classic adaptive time step criterium on the property angular momentum.
