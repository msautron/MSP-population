\doxysubsection{Detailed Description}
Class to handle the generation of a list of values. 

The class usage is based on the methods \mbox{\hyperlink{classutilities_1_1_list_generator_a76aed5fb6b11dbdcc5ca185db39a370e}{get()}}, \mbox{\hyperlink{classutilities_1_1_list_generator_a6549876a11c9be231ee53ea3be7cae7b}{next()}} and \mbox{\hyperlink{classutilities_1_1_list_generator_ac185ec122e6804a228d612a4c4e39644}{empty()}}. \mbox{\hyperlink{classutilities_1_1_list_generator_a76aed5fb6b11dbdcc5ca185db39a370e}{get()}} return the current value, \mbox{\hyperlink{classutilities_1_1_list_generator_a6549876a11c9be231ee53ea3be7cae7b}{next()}} upate the value and \mbox{\hyperlink{classutilities_1_1_list_generator_ac185ec122e6804a228d612a4c4e39644}{empty()}} return true if the generator reach the ends. If \mbox{\hyperlink{classutilities_1_1_list_generator_ac185ec122e6804a228d612a4c4e39644}{empty()}} is true calling \mbox{\hyperlink{classutilities_1_1_list_generator_a6549876a11c9be231ee53ea3be7cae7b}{next()}} or \mbox{\hyperlink{classutilities_1_1_list_generator_a76aed5fb6b11dbdcc5ca185db39a370e}{get()}} throws an out\+\_\+of\+\_\+range error.
