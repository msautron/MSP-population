V 2.10.0 [30-05-2024]
    - Changed the standard behaviour of SEVN when the star  are flagged as WR. Before the star automatically
      jumped to a pureHe track, but we realiase this could introduce some minor bias in the stellar evolution.
      We introduce a new runtime parameter turn_WR_to_pureHe so that we can split the flagging from the effect.
      Internally in SEVN a star is still flagged as WR based on the runtime parameter star_tshold_WR_envelope.
      However now a WR flagged star is turned into pureHe just if the parameter turn_WR_to_pureHe is set to True.
      The default is False, so by default a WR flagged star will be jump to pureHe track. In this case,
      a star can jump to pureHe tracks if it completely lose the envelope (based on the runtime parameter ev_naked_tshold).

    - Updated Klencki lambda with a new tables and a new handling of systems with small radius (outside the validity of the fitting equations).
      For star with R<Rtams, the lamnda is estimated as lambda(Rtams)*Rtams/R so that the binding energy is constant at the value of the TAMS
       and we avoid spikes at very high values due to the extrapolation of the lambda fitting equations.
